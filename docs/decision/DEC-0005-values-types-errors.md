# DEC-0005 数值、类型与异常

- 状态：Accepted
- 日期：2026-10-28
- 覆盖评审条目：P0-4、P1-1、P1-2、P2-5（Q5、Q9）


## 背景

构想层定义了值类型和各指令支持的类型，但跨类型运算、溢出、除零、移位范围、比较规则、异常时是失败还是返回空值，都没有统一规则。这些规则直接决定脚本结果，属于共识。

另外，浮点运算在不同架构上可能得出不同结果（例如 FMA 融合），不能进入共识路径。构想层已经规定公共域禁止浮点数，但只覆盖了浮点字面量。


## 决策

### 1. 值类型

Nil、Bool、Byte、Rune、Int（int64）、BigInt（绝对值不超过 1016 位）、Float（float64，私有域）、String、Bytes、RegExp、Time、Script、切片（具体类型的切片与 `[]any`）、Dict、模块 / 对象。

- **Bytes 即 `[]Byte`**，可以 `SLICE`、`INDEX`、`SIZE`。
- **String 不检查 UTF-8 合法性**，按字节比较。
- Script 携带版本号（DEC-0004）。

### 2. Float 是私有域类型（Q9）

**公共验证中，任何指令产生 Float 值即失败**，不论这个值进入数据栈、实参区、局部域、全局变量、集合，还是作为表达式的中间操作数。

实现上只需要在构造 Float 值的一处检查。浮点字面量、`FLOAT` 转换、`ANYS{Float}`、`RANGE` / `RANDOM` 的浮点分支、模块方法返回浮点数，都由这一条覆盖，不必逐个限制。私有域里浮点照常使用。

### 3. 数值提升

- 整数类按 Byte → Rune → Int → BigInt 提升。Byte、Rune 参与算术时先提升为 Int，结果至少是 Int。
- 有 BigInt 参与时结果为 BigInt，不自动降回 Int。BigInt 结果的绝对值超过 1016 位即失败，这样运行时的任何 BigInt 都能写回字面量。
- 私有域：Int 与 Float 运算提升为 Float；BigInt 与 Float 没有共同类型，运算即失败（与构想层值集的提升规则一致）。
- Bool、String、Bytes、Nil 不是数值，参与算术即失败（`ADD` 的拼接除外）。
- **表达式 `()` 不接受 BigInt 操作数**。构想层的符号指令只支持 Int（以及私有域的 Float），BigInt 运算使用命名指令（`ADD`、`SUB`、`MUL`、`DIV`、`NEG` 和位运算）。表达式的结果是 Int，私有域里也可能是 Float。

各指令支持的类型以构想层为准：`MOD`、`POW`、`DIVMOD` 不支持 BigInt；`ADD`、`SUB`、`MUL`、`DIV`、`NEG` 与位运算支持 BigInt。

### 4. 溢出与异常（一律失败）

「整数溢出即失败」（Q9）指算术运算：

- Int 的加、减、乘、取负、幂溢出即失败。Go 本身静默回绕，`MinInt64 / -1` 和 `-MinInt64` 的结果仍是 `MinInt64`，实现必须显式检查。
- 除数或模数为零即失败。
- 除法向零截断，余数的符号与被除数相同（同 Go）。
- `POW` 的指数为负即失败；`0^0 = 1`。

位运算不做溢出检查，按二进制补码处理（Go 的 `big.Int` 也这样定义）：

- Int 的移位数必须在 `[0, 63]` 之内，否则失败。左移移出的位丢弃；右移为算术右移。
- BigInt 的移位数必须非负；左移结果的绝对值超过 1016 位即失败。

### 5. 比较

- `EQUAL` / `NEQUAL`：数值类先提升再按值比较（Byte 65 等于 Int 65，Int 与值相同的 BigInt 相等）；String 与 String、Bytes 与 Bytes、Script 与 Script 按字节比较；Time 按时刻比较；Bool 与 Bool 比较；Nil 只等于 Nil。两边类别不同时结果为「不相等」，不失败。切片、字典、RegExp、模块 / 对象不可比较，比较即失败。
- `LT` / `LTE` / `GT` / `GTE`：只用于数值、String、Bytes、Time，且两边类别相同，否则失败。String 与 Bytes 按字节从左到右比较。
- `WITHIN`：只用于数值，按构想层的类型清单。
- 私有域的 Float 按 IEEE 754 比较，NaN 不等于任何值。

### 6. 拼接与合并

- `ADD` 只允许 String + String、Bytes + Bytes，混用即失败。结果受单项大小上限约束（DEC-0007）。
- 字典合并（`ADD`）返回一个新字典：先保留左侧的键及其顺序，右侧新增的键按其顺序追加，重复的键取右侧的值。

### 7. 转换的补充规则

构想层 `8.转换指令.md` 的转换表为准，补充：

- `RUNE`：结果落在代理区 `0xD800–0xDFFF` 即失败。
- `BYTE`：值不在 `[0, 255]` 即失败（包括负数）。
- `INT(String)` 解析失败即失败。
- `BOOL` 不接受切片、字典、Bytes。判空用 `SIZE BOOL`。
- `BYTES(Int)` 为 8 字节大端补码，`INT(Bytes)` 要求恰好 8 字节、按大端补码还原，两者对称。
- `BYTES(BigInt)` 与 `BIGINT(Bytes)` 只处理绝对值，会丢失符号。这是已知的局限，在指令说明中提示。
- `ANYS{T}` 对每个成员按 T 的转换规则转换，任一成员不能转换即失败。

### 8. PACK

**PACK 定义为「每个成员做 `BYTES` 转换，再首尾相接」**，不另设一套「基础二进制形态」，只维护一张转换表。成员不能转为 Bytes 时失败。

PACK 的结果不带长度信息，`["ab", "c"]` 与 `["a", "bc"]` 的结果相同。用于哈希承诺时，如果成员长度可变，应先固定长度或自行加入长度字段。这一点在指令说明中提示。

### 9. SLICE 与字符串

`SLICE` 只用于切片和 Bytes，对 String 使用即失败，以免切断 UTF-8 字符。字符串截取用 `SUBSTR`。

### 10. 异常处理的归类（P1-2）

每条指令的异常都属于以下三类之一。Spec 中每条指令有一行「异常」，写明所属类别：

| 类别 | 处理 | 指令 |
| --- | --- | --- |
| 按位置访问 | 越界即失败（同 Go 的切片越界） | `SLICE`、`INDEX`、`POPS`、`TOPS`、`PEEK`、`PEEKS`、`SHIFT`、`CLONE`、`VIEW`、`&[n]` |
| 按键查找 | 缺失返回 Nil（同 Go 从 map 取不存在的键） | `ITEM` |
| 明确声明的宽松行为 | 按指令说明 | `SUBSTR` 返回已截取的部分；MODEL 内 `$[n]` 越界返回 Nil；`MAP` 丢弃 Nil 结果 |

Nil 流入后续指令时：参与算术即失败；`BOOL(Nil)` 为 false；`EQUAL` 只与 Nil 相等。

### 11. 值语义

- **除字典外，所有值不可变。** 产生新内容的运算总是返回新值。
- `SLICE` 与原切片共享底层数组。因为切片不可变，共享是安全的，且效率更高。
- `EXTEND` 先复制底层数组再扩展，不会写穿共享的父切片。
- 字典可以被 `SET`、`DEL`、`CLEAR` 就地修改；`COPY` 是浅复制。
- **字典的值（递归地，包括值中切片的成员）不能包含字典**（Q5）。在 `DICT`、`SET`、字典合并时检查，违反即失败。切片可以包含字典。

最后一条同时解决两个问题：`COPY` 的浅复制之后，两个字典不会共享可变的内层字典；字典也无法直接或间接地包含自身，`PACK`、比较、打印等递归操作不会陷入循环。切片不可变，只能由已经存在的值构造，本身形不成循环，所以只需约束字典。


## 理由

- **默认失败**：类型不匹配、溢出、越界时返回一个「合理的」值，看似友好，实际是让脚本在作者没有预料的状态下继续执行。默认通关的原则下（P0-1），这类静默继续最终更可能变成放行。
- **规则贴近 Go**：作者和多数实现者熟悉 Go，越界失败、缺键返回零值、截断除法、补码位运算都与 Go 一致，记忆成本最低。差异只在 Go 静默回绕的地方（算术溢出），这里改为失败。
- **Float 一处拦截**：Float 有多个来源，逐个指令限制容易遗漏；在值的构造处检查，新增指令也不会漏。
- **表达式不接受 BigInt**：遵从构想层符号指令的类型定义，表达式保持为简单的 Int 运算。BigInt 的运算本来就需要按字数计成本（DEC-0007），留在命名指令里更清楚。


## 影响

- Spec 需要一张「运算 × 类型 → 结果或失败」的矩阵，覆盖运算、比较、转换三类指令。
- 每条指令的 Spec 条目增加「异常」一行。
- 实现中 Float 的构造必须集中在一处。
- 测试向量需要覆盖每一类溢出、除零、移位越界、代理区、跨类别比较。
- 构想层 `9.运算指令.md` 中 `MOD`、`POW` 写的是「输入什么类型返回什么类型」，按第 3 条，Byte、Rune 输入的结果是 Int。
