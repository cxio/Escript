## 概述

私有执行是节点在本地运行脚本的模式，结果不参与共识（SPEC-0005 第 10 条）。本篇定义私有执行中与公共执行不同的部分：Float 的运算与文本解析，私有通道（交互指令与 `FN_PRINTF`），私有专属指令（`SYS_TIME`、`SHELL`、`FN_PRIV`、`EXT_PRIV`），私有方法，以及值的默认文本形式。

本篇的规则只约束私有执行的实现，不是共识规则。为了让同一脚本在不同实现上的私有执行结果一致，本篇仍给出确定的定义，并以 Go 的标准库为参考实现。


## 规格正文

### 1. 两种执行的差别

| 项目 | 公共执行 | 私有执行 |
| --- | --- | --- |
| Float 与 `[]Float`（浮点字面量、值集、`FLOAT`、`ANYS[7]`、运算结果、取值） | 产生即失败 | 第 2 条 |
| `INPUT` | 同 `END` | 第 3 条 |
| `OUTPUT`、`BUFDUMP`、`PRINT`、`FN_PRINTF` | 空操作，照常消费实参 | 第 3 条 |
| `END` | 结束 | 忽略 |
| `SYS_TIME`、`SHELL`、`FN_PRIV`、`EXT_PRIV` | 执行到即失败 | 第 4–6 条 |
| `MO_FMT` 与方法表中标记 P 的方法 | 执行到即失败 | SPEC-0105 |
| 硬限额（SPEC-0006 第 1 条） | 适用 | 适用 |
| 成本预算 | 共识值 | 第 8 条 |

除上表外，私有执行与公共执行的规则相同：同一脚本在私有执行中通过，不意味着在公共执行中通过，反之亦然。

### 2. Float

- Float 是 IEEE 754 binary64。运算按 Go `float64` 的语义（参考实现），NaN、±Inf 可以在运算中产生。
- Go 允许编译器把乘加融合为一次运算（FMA），不同平台的末位结果可能不同。私有执行不要求跨平台逐位一致。
- 各指令对 Float 的规则见 SPEC-0102（转换、运算、比较）、SPEC-0104（`RANDOM`、`CMPFLO`、`RANGE`）、SPEC-0105（`MO_MATH`）。
- **`FLOAT(String)`**：按 Go `strconv.ParseFloat(s, 64)` 的语法（十进制或十六进制浮点，`inf`、`infinity`、`nan` 不区分大小写，可带符号）。超出范围时得到 ±Inf 而不失败（与 `ParseFloat` 返回 `ErrRange` 时的值相同）；语法不符即失败。

### 3. 私有通道

私有通道由宿主在私有执行中提供（SPEC-0008 第 7 条）。INPUT 与 OUTPUT 的缓存区是两个独立的先进先出队列，属于验证级状态（SPEC-0005 第 3.1 条），`GOTO` 目标、`EMBED` 代码与 EVAL 代码共用。

| 指令 | 私有执行 |
| --- | --- |
| `INPUT[n]` | n ≥ 1：缓存区至少有 n 项时，取出头部 n 项按顺序返回；n = 0：缓存区非空时取出全部。否则**中断退出**（SPEC-0005 第 7.2 条，效果同公共执行中的 `END`），缓存区不变 |
| `OUTPUT` | 把实参按顺序追加到 OUTPUT 缓存区；实参可以为 0 项 |
| `BUFDUMP[id]` | 把 id（Int）与缓存区的全部内容（`[]any`）交给宿主注册的处理器，然后清空缓存区；没有处理器时只清空。不阻塞：处理器的结果不影响执行 |
| `PRINT` | 把实参写到节点的控制台，形式同 Go `fmt.Println`：各实参按第 7 条的默认形式，以空格分隔，末尾换行 |
| `FN_PRINTF` | 实参 1 必须是 String（格式串），否则失败；其余实参按第 7 条的对应关系交给 Go `fmt.Printf` |

- INPUT 缓存区的内容由宿主在执行之前注入（构想层：「应当先注入数据，然后再执行脚本」）。
- OUTPUT 缓存区没有共识限额，节点自行限制；超出节点的限制时，节点可以使本次私有执行失败。
- 中断退出不改变通关状态：此前已经「通过」的，顶层判定仍为通过（构想层）。

### 4. `SYS_TIME[k]`（164）

读取节点的当前时间。条目编号见 SPEC-0002 第 6.14 条。

| k | 条目 | 结果 |
| --- | --- | --- |
| 0 | 当前时间 | Time：时刻为当前 Unix 毫秒，偏移为节点本地时区在该时刻的偏移 |
| 1 | `Stamp` | Int：当前 Unix 毫秒 |
| 2–10 | `Year`、`Month`、`YearDay`、`Day`、`WeekDay`、`Hour`、`Minute`、`Second`、`Millisecond` | Int：按节点本地时区，取值范围同 `MO_TIME` 的同名方法（SPEC-0105 第 2 条） |
| 11 | `Microsecond` | Int：0–999999 |

同一次执行中多次读取，各次读取当时的时间。宿主可以在执行开始时固定时间，以便测试。

### 5. `SHELL`（155）

- 关联数据是命令文本，首行为解释器标记（`#!`，Shebang），不限语言（构想层）。
- **默认关闭**（SPEC-0008 第 7 条）。节点必须显式配置白名单，例如按命令文本的 BLAKE3-256 哈希，或按签名者授权；不在白名单中、或功能未开启，即失败。
- 在独立的进程中执行，不提供标准输入，不继承脚本的任何状态。
- 返回一个值：标准输出的全部内容作为 String；没有输出时为 Nil。输出超过 8191 字节即失败（单项大小）。
- 进程以非零状态退出、超过节点设定的时限，即失败。标准错误不进入结果。

### 6. `FN_PRIV`、`EXT_PRIV`（220、253）

- 私有节点按索引注册函数：`FN_PRIV` 为 `u8`，`EXT_PRIV` 为 `u16be`。每个注册项声明实参个数、返回值个数与实现。
- 执行时按注册项的声明取得实参、放置返回值。索引没有注册，即失败。
- 加载期对它们的处理见 SPEC-0003 第 4 条（与私有配置无关）。

### 7. 值的默认文本形式

用于 `PRINT`、`MO_FMT` 的 `Sprint` / `Sprintln`，以及格式化动词 `%v`：

| 值 | 形式 |
| --- | --- |
| Nil | `<nil>` |
| Bool | `true`、`false` |
| Byte、Rune、Int、BigInt | 十进制 |
| Float | 同 Go `%v`（`strconv.FormatFloat(x, 'g', -1, 64)`） |
| String | 原文 |
| Bytes | `[` 各字节的十进制，以空格分隔 `]`，同 Go 对 `[]byte` 的 `%v` |
| 切片 | `[` 各成员的默认形式，以空格分隔 `]` |
| Dict | `map[` 各条目 `键:值`，以空格分隔，**按插入顺序** `]` |
| Time | RFC 3339：毫秒不为 0 时带 3 位小数；偏移为 0 时写 `Z` |
| RegExp | 源文本 |
| Script | 同其字节码的 Bytes 形式 |
| 模块对象 | `<` 模块指令名 `>`，如 `<MO_MATH>` |

交给 Go `fmt` 的格式化函数（`FN_PRINTF`、`Sprintf`）时，值的对应关系：Nil 为 `nil`，Bool 为 `bool`，Byte 为 `uint8`，Rune 为 `int32`，Int 为 `int64`，BigInt 为 `*big.Int`，Float 为 `float64`，String 为 `string`，Bytes 为 `[]byte`；其它类型以上表的默认形式作为 `string` 参与格式化。

### 8. 预算

- 硬限额在私有执行中照常适用（SPEC-0006 第 1 条）。
- 成本照常计量。单输入预算由节点自行设定，默认取 `MaxInputScriptCost` 的核心默认值；交易与区块预算不适用。
- 私有通道的数据量、`SHELL` 的时限等，由节点自行限制。


## 边界与限制

- 私有执行的结果只影响本地，不得用于共识判断（SPEC-0005 第 10 条）。
- 处理器、白名单与私有函数的注册方式属于节点的配置，不在本篇规定。


## 待决问题

## 对 Plan 的约束

- 公共执行与私有执行共用同一个解释器，以执行模式切换第 1 条表中的行为；不得为私有执行另写一套指令实现。
- `SHELL` 的白名单检查必须在启动进程之前完成，并有「未配置白名单即失败」的测试。
- 私有通道通过宿主接口注入（INPUT 数据、BUFDUMP 处理器、控制台输出），核心包内没有 I/O（SPEC-0008）。
