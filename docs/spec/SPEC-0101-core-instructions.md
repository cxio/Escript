## 概述

本篇逐条定义 opcode 0–66 的语义、异常与成本。指令的格式（附参、关联数据、实参与返回值个数）见 SPEC-0002 第 6 条；实参的取得、返回值的去向、块与局部域、通关状态机、子执行见 SPEC-0005。本篇不重复这些框架，只写每条指令自己的规则。

第 1 条是 SPEC-0101 ～ 0106 共用的约定。


## 规格正文

### 1. 通用约定（SPEC-0101 ～ 0106）

#### 1.1 条目的写法

每条指令给出语义、异常与成本。实参与返回值的个数以 SPEC-0002 的格式表为准，条目中只写类型与含义。私有执行中不同的行为见 SPEC-0106，本篇只写公共执行的行为与两种执行相同的部分。

#### 1.2 实参的类型

- **编号**：实参 1 是最先加入实参区的一项，或数据栈中最深的一项（SPEC-0005 第 4 条）。
- **整数类实参**〔R-22〕：用作下标、位置、数量、次数、移位数的实参，接受 Byte、Rune、Int，按其整数值使用。BigInt（即使在 int64 范围内）与其它类型即失败。
- **Bool 实参**：必须是 Bool，不做真值转换；需要时先用 `BOOL`。
- **切片**：除非条目另有说明，「切片」包括 Bytes（SPEC-0004 第 2 条），其成员是 Byte。String 不是切片。
- **键与键集**：键是 String。键集是成员全为 String 的切片：`[]String`，或成员全为 String 的 `[]any`。
- 实参的类型不在条目列出的范围内，即失败（DEC-0005「默认失败」）。

#### 1.3 位置

长度为 n 的序列，位置 p 换算为下标 i：p ≥ 0 时 i = p，p < 0 时 i = n + p。要求 0 ≤ i < n，否则失败。个别条目允许 i = n（例如 `SLICE` 的起点），在条目中写明。

#### 1.4 结果的限额

单项大小、集合成员数、BigInt 的范围、公共执行中的 Float，都在产生值时统一检查（SPEC-0004 第 3 条、SPEC-0006 第 1 条）。各条目不再重复；条目中的「异常」只列本指令特有的失败情形。

#### 1.5 异常

「异常」一行列出失败情形，并按 DEC-0005 第 10 条标注类别：**按位置**（越界即失败）、**按键**（缺失得 Nil）、**宽松**（按条目说明）。没有标注类别的，一律失败。

#### 1.6 成本

按 SPEC-0006 第 2.1 条的记号（`K`、`B(x)`、`a`、`r`、`D`、`m`）。块指令的成本不含其块体，块体内各指令的成本另计。

### 2. 值指令 `[0-18]`

#### 2.1 字面量

| 码值 | 指令 | 结果 | 成本 |
| --- | --- | --- | --- |
| 0 | `NIL` | Nil | `K` |
| 1、2 | `TRUE`、`FALSE` | Bool | `K` |
| 3 | Byte | Byte，即数据字节 | `K` |
| 4 | Rune | Rune | `K` |
| 5 | 整数 | Int | `K` |
| 6 | 大整数 | BigInt：符号取附参 bit7，绝对值取数据 | `K`，`D` = L |
| 7 | 浮点数 | Float。公共执行中即失败（SPEC-0004 第 3 条） | `K` |
| 8 | 字符串 | String | `K`，`D` = L |
| 10 | `DATA` | Bytes | `K`，`D` = L |
| 11 | 正则 | RegExp：加载期已编译的正则与其源文本 | `K`，`D` = L；编译成本已在加载期计入 |
| 12 | `DATE` | Time：时刻取数据，偏移为 0〔R-05〕 | `K` |
| 16 | `CODE` | Script：字节码取数据，版本取本指令所在段的版本（SPEC-0007 第 2 条）。数据在此不解码，`EVAL` 时才加载 | `K`，`D` = L |

`CODE` 的结果是源码类值（SPEC-0006 第 1 条）。

#### 2.2 值集（9）

按成员指令依次得到成员值，再统一为最大的类型（SPEC-0004 第 4 条）：

| 成员 | 结果 |
| --- | --- |
| 全为 Bool | `[]Bool` |
| 全为 String | `[]String` |
| 全为 Byte | Bytes |
| 数值，最大为 Rune / Int / BigInt | `[]Rune` / `[]Int` / `[]BigInt` |
| 数值，含 Float | `[]Float`，各成员转为 Float。公共执行中即失败〔R-06〕 |

- 成员的类别在加载期已检查（SPEC-0003 第 3 条第 5 项）。
- 结果不是 Bytes 时，成员数超过 1024 即失败；这一检查在运行时进行，不会执行到的值集不受影响。
- 成本：`K + m`，`D` 为 String、BigInt 成员的字节数之和（结果为 Bytes 时为其字节数）。

#### 2.3 `DICT`（13）

- 实参 1：键集。实参 2：值序列，任一切片。
- 按位置配对：第 i 个键对应第 i 个值。键多于值时，多出的键对应 Nil；值多于键时，多出的值忽略（构想层）。
- 重复的键〔R-23〕：后出现的值覆盖先前的值，条目保持首次插入的位置。
- **字典约束**：每个值不是 Dict，也不是（递归地）含有 Dict 的切片（SPEC-0004 第 2 条）。
- 结果是一个新 Dict，按插入顺序迭代。
- 异常：实参 1 不是键集；实参 2 不是切片；违反字典约束。
- 成本：`K + m`，m 为键数加上检查字典约束时遍历的成员数。

#### 2.4 `SCRIPT`（17）

1. 外部加载计数已达 8 即失败（SPEC-0006 第 1 条）。
2. 按附参向宿主加载（SPEC-0008 第 5.1 条）：目标不存在即失败；取不到即数据不可用。
3. 外部加载计数加 1。结果是 Script：字节码为加载到的脚本，版本为宿主返回的版本。此处不检查版本是否已知，也不解码（SPEC-0007 第 2 条），`EVAL` 时才检查。

- 结果是源码类值（上限 16KB）。
- 成本：`K + 200`，`D` 为脚本字节数。`1 + r + 200` 在加载之前计入，`B(D)` 在取到之后计入（SPEC-0006 第 2 条）。

#### 2.5 `GVAL`（18）

按附参的字段索引取宿主提供的值。字段表、值的类型、取不到时返回 Nil 还是数据不可用，都由宿主规格定义（SPEC-0008 第 4 条，Evidcoin 见 SPEC-0901〔P-08〕）。

成本：`K`，`D` 为字段值中变长内容的字节数。

### 3. 截取指令 `[19-24]`

| 码值 | 指令 | 语义 | 成本 |
| --- | --- | --- | --- |
| 19 | `@` | 后一条指令的返回值依次加入实参区 | 1 |
| 20 | `&`（存值） | 后一条指令的返回值依次加入当前局部域 | 1 |
| 23 | `~` | 后一条指令的实参直接从数据栈取，不读实参区 | 1 |
| 24 | `_` | 丢弃后一条指令的返回值 | 1 |

前缀的组合与目标由加载期检查（SPEC-0003 第 4 条），去向与容量检查见 SPEC-0005 第 4、5 条。

**`&[n]`（21）**：引用当前活动记录的局部域中位置 n 的值（第 1.3 条，n 为 `i8`，按加入局部域的先后编号）。默认去向是实参区（SPEC-0002 第 4 条）。

- 异常：按位置。
- 成本：`K`。

**`$X`（22）**：引用词法上最近的 `EACH`、`MAP` 或 `FILTER` 的当前迭代的循环变量（`$Value`、`$Key`、`$Object`、`$Size`，SPEC-0005 第 12 条）。默认去向是数据栈。

- 成本：`K`。

### 4. 栈操作指令 `[25-35]`

栈操作指令直接读写数据栈，不读实参区。h 为执行时的栈高度。返回多项时，按它们在栈中自底向上的顺序返回。「引用」是返回原值本身：除 Dict 外的值都不可变，引用与复制没有区别（SPEC-0004 第 6 条）。

| 码值 | 指令 | 语义 | 异常 | 成本 |
| --- | --- | --- | --- | --- |
| 25 | `NOP` | 取出实参区的全部条目（可以为 0 项）并丢弃 | — | `K` |
| 26 | `PUSH` | 实参依次入栈，实参 1 最先入栈 | 栈高度达到 256 | `K`，r 计为 a |
| 27 | `POP` | 移除栈顶项并返回它 | 栈空：按位置 | `K` |
| 28 | `POPS[n]` | 移除栈顶 n 项并返回；n = 0 为全部（栈空时返回 0 项） | n > h：按位置 | `K` |
| 29 | `TOP` | 引用栈顶项 | 栈空：按位置 | `K` |
| 30 | `TOPS[n]` | 同 `POPS[n]`，但不移除 | n > h：按位置 | `K` |
| 31 | `PEEK[p]` | 引用位置 p 的项，从栈底计（第 1.3 条，序列长度为 h） | 按位置 | `K` |
| 32 | `PEEKS[p, c]` | 起点 i 由 p 按第 1.3 条换算；c = 0 引用 i 到栈顶的全部，否则引用 c 项 | i 无效、i + c > h：按位置 | `K` |
| 33 | `SHIFT[n]` | 同 `POPS[n]` 移除，结果封装为一个 `[]any` | n > h：按位置 | `K + m` |
| 34 | `CLONE[n]` | 同 `TOPS[n]` 引用，结果封装为一个 `[]any` | n > h：按位置 | `K + m` |
| 35 | `VIEW[c, p]` | 范围同 `PEEKS[p, c]`，结果封装为一个 `[]any` | 同 `PEEKS` | `K + m` |

- `PEEKS`、`VIEW` 的起点必须是有效下标，因此栈空时即失败，即使 c = 0。
- `SHIFT`、`CLONE`、`VIEW` 的结果可以是空的 `[]any`（n = 0 且栈空）。
- `VIEW` 的附参次序是「条目数，起点」，与 `PEEKS` 相反（构想层）。

### 5. 集合指令 `[36-45]`

#### 5.1 `SLICE`（36）

- 实参 1：切片。实参 2：起点 p（整数类）。附参：大小 s，0 表示到末尾。
- 起点 i 按第 1.3 条换算，但允许 i = n（得到空切片）。s ≠ 0 时要求 i + s ≤ n。
- 结果的成员类型与实参 1 相同（Bytes 得到 Bytes），可以与实参 1 共享底层存储（DEC-0005 第 11 条）。
- 异常：实参 1 是 String（DEC-0005 第 9 条）或其它非切片类型；按位置。
- 成本：`K`（`D` = 0）。

#### 5.2 `REVERSE`（37）

- 实参：切片。结果是成员逆序的新切片，成员类型不变。
- 成本：`K + m`（Bytes：`D` 为字节数）。

#### 5.3 `MERGE`（38）

- 实参：不定数量，每个都是切片。结果是按实参顺序首尾相接的新切片。
- 成员类型〔R-23〕：全部实参的成员类型相同时取该类型（全为 Bytes 时得到 Bytes）；否则为 `[]any`，Bytes 实参贡献 Byte 成员。没有实参时为空的 `[]any`。
- 异常：任一实参不是切片。
- 成本：`K + m`（结果为 Bytes 时 `D` 为其字节数）。

#### 5.4 `EXTEND`（39）

- 实参 1：目标切片。其余实参：按顺序追加的成员。
- 成员类型〔R-23〕：目标为 `[]any` 时接受任意值；目标为 `[]E` 时，每个追加的成员都必须恰好是 E 类型，不做提升（Bytes 只接受 Byte）。
- 结果是新切片，先复制再追加，不改变目标（DEC-0005 第 11 条）。
- 异常：目标不是切片；成员类型不符。
- 成本：`K + m`，m 为结果的成员数（Bytes：`D` 为结果字节数）。

#### 5.5 `PACK`（40）

- 实参：切片。每个成员按 `BYTES` 转换（SPEC-0102 第 2.4 条），按顺序首尾相接（DEC-0005 第 8 条）。
- 不能转为 Bytes 的成员即失败：Dict、Float、Bytes 与 `[]Rune` 以外的切片、模块对象。
- 结果不含长度信息，`["ab", "c"]` 与 `["a", "bc"]` 的结果相同。用于哈希承诺时，变长成员应先固定长度或自行加入长度字段。
- 成本：`K + m`，`D` 为结果字节数。

#### 5.6 `SPREAD`（41）

- 实参：切片。按顺序返回全部成员，个数为 `*`（可以为 0）。Bytes 的成员是 Byte。
- 成本：`K`（r 为成员数）。

#### 5.7 `INDEX`（42）

- 实参 1：切片。实参 2：位置（整数类），或位置集（成员全为整数类的切片）。
- 位置：按第 1.3 条返回该成员。位置集：返回各位置的成员按顺序组成的新切片，成员类型与实参 1 相同（Bytes 得到 Bytes）；空的位置集得到空切片。
- 异常：按位置；实参 2 不是位置或位置集。
- 成本：`K + m`，m 为位置集的成员数。

#### 5.8 `ITEM`（43）

- 实参 1：Dict，或 Time、RegExp、BigInt、模块对象。实参 2：键或键集。
- Dict：键得到对应的值，键不存在得 Nil；键集得到一个 `[]any`，依次为各键的值。
- Time、RegExp、BigInt、模块对象〔R-23〕：v1 中它们没有可由 `ITEM` 读取的静态成员，结果为 Nil（键集则为全是 Nil 的 `[]any`）。它们的方法通过 `CALL` 调用（SPEC-0105）。
- 异常：按键；实参 1 为其它类型（包括切片），或实参 2 不是键或键集，即失败。
- 成本：`K + m`。

#### 5.9 `SET`（44）

- 实参 1：Dict。实参 2：键或键集。实参 3：值。
- 键：把该键的值设为实参 3。
- 键集：实参 3 是切片时，长度必须与键集相同，按位置一一赋值；实参 3 不是切片时，把它赋给每个键（构想层）。
- 赋值按顺序进行：已有的键改值，位置不变；新键追加在末尾；键集中重复的键，后者覆盖前者〔R-23〕。
- 每个被赋的值都要满足字典约束（第 2.3 条）。
- 返回实参 1，即同一个 Dict。修改对它的所有引用可见（SPEC-0004 第 6 条）。
- 异常：实参 1 不是 Dict；键集与值切片的长度不同；违反字典约束。
- 成本：`K + m`，m 为赋值的键数加上检查字典约束时遍历的成员数。

#### 5.10 `SIZE`（45）

- 实参：切片或 Dict。返回 Int：切片的成员数（Bytes 为字节数），Dict 的条目数。
- 异常：其它类型即失败，包括 String。String 的字节数用 `BYTES SIZE`，字符数用 `RUNES SIZE`。
- 成本：`K`。

### 7. 结果指令 `[51-57]`

| 码值 | 指令 | 语义 | 异常 | 成本 |
| --- | --- | --- | --- | --- |
| 51 | `PASS` | 实参 Bool：true 使当前脚本域「通过」并继续；false 为否决（SPEC-0005 第 7 条） | 实参不是 Bool | `K` |
| 52 | `CHECK` | 实参 Bool：true 使当前脚本域「通过」，false 使其「未通过」，都继续执行 | 实参不是 Bool | `K` |
| 53 | `GOTO` | SPEC-0005 第 11.1 条 | 见该条 | `K + 200`，`D` 为目标字节数，另计目标的加载期成本 |
| 54 | `EMBED` | SPEC-0005 第 11.2 条 | 见该条 | 同 `GOTO` |
| 55 | `EXIT` | 可选的单个实参；按 SPEC-0005 第 7.2 条结束。实参只在结束顶层时交给宿主，其它情形丢弃 | 实参多于 1 项 | `K` |
| 56 | `RETURN` | 可选的单个实参，为词法上最近的 `MAP` / `FILTER` 本轮的结果（无实参为 Nil）；结束本轮，同时结束其间的全部块（包括 `EACH`、`SWITCH`） | 实参多于 1 项 | `K` |
| 57 | `END` | 按 SPEC-0005 第 7.2 条结束；私有执行中忽略 | — | `K` |

`GOTO`、`EMBED` 的计费时点：`1 + a + 200` 在取数之前计入，`B(D)` 在取到之后计入，然后按 SPEC-0003 第 8 条计目标的加载期成本（SPEC-0006 第 2 条的例）。

### 8. 流程控制 `[58-66]`

块的执行、局部域与 IF 状态见 SPEC-0005 第 6 条，`SWITCH`、`EACH`、`BREAK`、`CONTINUE` 的完整规则见 SPEC-0005 第 12 条。

| 码值 | 指令 | 语义 | 异常 | 成本 |
| --- | --- | --- | --- | --- |
| 58 | `IF` | 实参 Bool，记入当前活动记录的 IF 状态；为 true 时执行块体 | 实参不是 Bool | `K` |
| 59 | `ELSE` | IF 状态为 false 时执行块体 | — | `K` |
| 60 | `SWITCH` | 实参 1 为标的值，实参 2 为分支值切片；执行块体 | 实参 2 不是切片；其长度不等于块体内直接 `CASE` 的个数 | `K` |
| 61 | `CASE` | 第 i 个 `CASE` 按 `EQUAL` 的语义比较标的值与第 i 个分支值：相等则执行块体，然后结束 `SWITCH`；否则跳过块体 | 比较的值不可比较（SPEC-0004 第 5 条） | `K + 1` |
| 62 | `DEFAULT` | 执行块体，然后结束 `SWITCH` | — | `K` |
| 63 | `EACH` | 实参：切片或 Dict；逐轮执行块体 | 实参为其它类型 | `K` + 每轮 1（被跳过的 Dict 键也计） |
| 64 | `CONTINUE` | 可选实参 Bool：无实参或为 true 时，结束最近的 `EACH` 的本轮；为 false 时什么都不做 | 实参不是 Bool；多于 1 项 | `K` |
| 65 | `BREAK` | 同上，结束最近的 `EACH` 或 `SWITCH` | 同上 | `K` |
| 66 | `BLOCK` | 执行块体 | — | `K` |

`EACH` 的每轮成本在该轮开始时计入。

## 对 Plan 的约束

- 第 1 条的约定（整数类实参、Bool 实参、键集、位置换算、字典约束）各实现为一个公共函数，供全部指令使用，不在各指令中分别实现。
- 每条指令的测试向量覆盖：正常；边界（位置恰在两端、空集合、恰好 1024 个成员、栈高度恰为 255）；本篇列出的每一种失败情形（DEC-0001 第 5 条）。
- 栈操作的多值顺序、`MERGE` 与 `EXTEND` 的成员类型、`DICT` 与 `SET` 的重复键、`ITEM` 作用于对象，各要有专门的向量。
