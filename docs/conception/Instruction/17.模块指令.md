# 模块指令

模块用于引入分门别类的功能板块。

模块中定义的方法可以通过两种方式调用：*静态索引*；*动态方法名*。

附参为零执行模块指令，就会调用其构造方法，创建一个模块对象。然后就可以由通用的 `CALL` 指令调用其开放的方法。

> **约定：**
> 模块成员函数返回多个值时，会被封装为一个切片。无自动展开能力。


## 定义

指令码区间：`[225-250]`，26个。


### 基础模块

```go
码值    指令字          说明
-----------------------------------------------------------
225     MO_MATH(1){}    数学运算类
        // 汇聚专用于数学运算的高阶操作。
        // 附参：方法名索引。
        // 0: 系统保留，用于创建模块对象。可用 CALL 调用。
        // 1-255: 方法名索引。
        // 说明：
        // 除了零值附参保留外，最多可支持254个方法名。
        // 成员：
        // T: 支持 Int 和 Float，返回值类型即参数类型。
        // - Abs(x T) T
        // - Ceil(x T) T
        // - Floor(x T) T
        // - Pow(x, y T) T
        // - Max(x, y T) T
        // - Min(x, y T) T
        // - Mod(x, y T) T
        // - ……
        // 例：
        // 静态引用方法索引，此处花括号内的名称为索引别名。
        // 静态引用对脚本执行更友好。
        // {-100} MO_MATH{Abs}      // => 100
        // {-100} MO_MATH[1]        // 同上，假设 Abs 索引为 1
        // {1} {99.0} MO_MATH{Max}  // => 99.0
        //
        // 例：
        // 也可以使用 CALL 调用，方法名为字符串，运行时确定。
        // 此方式可突破 254 个成员的限制。
        // MO_MATH "Abs" {-100} CALL[3]         //=> 100
        // MO_MATH "Max" {-1} {99.0} CALL[4]    //=> 99.0

226     MO_FMT(1){}     数据格式化（Go:fmt）
        // 汇聚基本的格式化方法。
        // 主要是对 go.fmt 标准库的局部成员封装。
        // 成员：
        // - Sprint(a ...any) string
        // - Sprintf(format string, a ...any) string
        // - Sprintln(a ...any) string
        // ……

227     MO_TIME(1){}    时间处理
        // 用于有关时间的更进一步处理。
        // 部分不确定性的方法只能由私有应用使用。
        // 成员：
        // ……

228-248 （未用）
```


### 标准模块包

此模块通过附参引用一个子模块，不支持子模块静态索引方法名。因此只能通过 `CALL` 调用。

```go
码值    指令字          说明
-----------------------------------------------------------
249     MO_XX(1){}      标准模块引用
        // 引用目标位置的子模块。
        // 附参：目标索引。
        // 友好：
        // 子模块名称可书写在花括号内。
        // 例：
        // MO_XX{Crypto}    // 引入 Crypto 模块
        // "Hello" CALL     // 调用目标模块的 Hello 方法
        //
        // 设计：
        // 256个标准模块的空间应已足够，
        // 但如需要更多支持，可使用扩展指令 EXT_MO，空间巨大。

250     MO_PRIV(1){}    私有模块引用
        // 为第三方私有应用预留空间。
        // 附参：目标索引。
        //
        // 设计：
        // 部分系统级模块也有「私有专属」逻辑，但它们服务于所有的私有。
        // 此指令可用于特定的第三方专属，无需兼容。
```
