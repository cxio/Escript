# 模块指令

模块用于引入分门别类的功能板块。

模块中定义的方法可以通过两种方式调用：*静态索引*；*动态方法名*。

除系统内置对象（`Time`, `RegExp`, `BigInt`）外，其它模块的零值附参索引模块的构造方法，创建一个模块对象，用于通用的 `CALL` 调用其开放的方法。

> **约定：**
> 模块成员函数返回多个值时，会被封装为一个切片。无自动展开能力。


## 定义

指令码区间：`[221-250]`，30个。


### 标准模块

```go
码值    指令字          说明
-----------------------------------------------------------
221     MO_TIME(1){}    时间处理
        // 用于有关时间的更进一步处理。
        // 部分不确定性的方法只能由私有应用使用。
        // 附参：方法名索引。
        // 成员：
        // 所有方法的首个实参为一个 Time|*Time 对象。
        // 方法索引按下列顺序从 1 开始，零值未用。P 为私有方法。
        // - Year(t) int            // 年
        // - Month(t) int           // 1-12
        // - Day(t) int             // 1-31
        // - Hour(t) int            // 0-23
        // - Minute(t) int          // 0-59
        // - Second(t) int          // 0-59
        // - Millisecond(t) int     // 0-999
        // - WeekDay(t) int         // 0-6，0 为星期日
        // - YearDay(t) int         // 1-366
        // - Date(t) []int          // [年, 月, 日]
        // - Clock(t) []int         // [时, 分, 秒]
        // - Unix(t) int            // 秒
        // - UnixMilli(t) int       // 毫秒
        // - Offset(t) int          // 时区偏移（秒）
        // - UTC(t) Time
        // - InOffset(t, sec int) Time
        // - AddMilli(t, ms int) Time
        // - AddDate(t, y, m, d int) Time
        // - Sub(t, u Time) int     // 毫秒差
        // - Format(t, layout string) string   // P
        // - Local(t) Time                     // P
        // - In(t, name string) Time           // P
        // 提示：
        // 日历取值按 Time 携带的固定偏移计算，不使用时区数据库。
        // 依赖布局语法或时区数据库的方法（Format/Local/In）仅限私有域。

222     MO_RE(1){}      正则表达式
        // 对正则表达式的完整方法集的定义和处理。
        // 静态的确定性方法便于公共域使用。
        // 附参：方法名索引。
        // 成员：
        // 所有方法的首个实参为一个 RegExp|*RegExp 对象。
        // 方法索引按下列顺序从 1 开始，零值未用。
        // s 为 String|Bytes，返回的文本类型与之相同。n < 0 表示全部。
        // - Match(re, s) bool
        // - Find(re, s) string|bytes|nil
        // - FindIndex(re, s) []int|nil
        // - FindSubmatch(re, s) []any|nil
        // - FindSubmatchIndex(re, s) []int|nil
        // - FindAll(re, s, n int) []string|[]bytes
        // - FindAllIndex(re, s, n int) [][]int
        // - FindAllSubmatch(re, s, n int) [][]any
        // - FindAllSubmatchIndex(re, s, n int) [][]int
        // - ReplaceAll(re, s, repl) string|bytes
        // - ReplaceAllLiteral(re, s, repl) string|bytes
        // - NumSubexp(re) int
        // - SubexpNames(re) []string
        // - SubexpIndex(re, name string) int
        // - String(re) string

223     MO_BINT(1){}    大整数运算
        // 对大整数类型的一些基本运算操作。
        // 附参：方法名索引。
        // 成员：
        // 所有方法的首个实参为一个 BigInt|*BigInt 对象。
        // 方法索引按下列顺序从 1 开始，零值未用。
        // I 为整数或大整数（整数提升为大整数）。
        // - Abs(x) BigInt
        // - Sign(x) int                // -1|0|1
        // - Cmp(x, y I) int            // -1|0|1
        // - Quo(x, y I) BigInt         // 截断除法（向零）
        // - Rem(x, y I) BigInt
        // - QuoRem(x, y I) []BigInt
        // - Div(x, y I) BigInt         // 欧几里得除法（余数非负）
        // - Mod(x, y I) BigInt
        // - DivMod(x, y I) []BigInt
        // - Pow(x, e int) BigInt
        // - ModPow(x, e, m I) BigInt
        // - ModInverse(x, m I) BigInt
        // - GCD(x, y I) BigInt
        // - Sqrt(x) BigInt             // 向下取整
        // - BitLen(x) int
        // - Bit(x, i int) int          // 二进制补码的第 i 位
        // - IsInt64(x) bool
        // - FillBytes(x, n int) bytes  // 绝对值，大端，左侧补零
        // 提示：
        // 加减乘、截断除法、取负与位运算由运算指令直接支持。

224     MO_MATH(1){}    数学运算类
        // 汇聚专用于数学运算的高阶操作。
        // 附参：方法名索引。
        // 0: 系统保留，用于创建模块对象。可用 CALL 调用。
        // 1-255: 方法名索引。
        // 说明：
        // 除了零值附参保留外，最多可支持255个方法名。
        // 成员：
        // T: 支持 Int 和 Float，返回值类型即参数类型。
        // - Abs(x T) T
        // - Ceil(x T) T
        // - Floor(x T) T
        // - Pow(x, y T) T
        // - Max(x, y T) T
        // - Min(x, y T) T
        // - Mod(x, y T) T
        // - Round(x T) T           // 0.5 远离零
        // - Trunc(x T) T
        // - Sign(x T) T
        // - Sqrt(x T) T            // 整数向下取整
        // - MulDiv(a, b, c Int) Int    // a*b/c，乘积按 128 位精确计算
        // 以下为私有方法（结果为 Float）：
        // - Exp(x T) Float
        // - Log(x T) Float
        // - Log2(x T) Float
        // - Log10(x T) Float
        // - Sin(x T) Float
        // - Cos(x T) Float
        // - Tan(x T) Float
        // - Atan(x T) Float
        // - Atan2(y, x T) Float
        // - Hypot(x, y T) Float
        // 方法索引按上列顺序从 1 开始。
        // 例：
        // 静态引用方法索引，此处花括号内的名称为索引别名。
        // 静态引用对公共域更友好。
        // {-100} MO_MATH{Abs}      // => 100
        // {-100} MO_MATH[1]        // 同上，假设 Abs 索引为 1
        // {1} {99.0} MO_MATH{Max}  // => 99.0
        //
        // 例：
        // 也可以使用 CALL 调用，方法名为字符串，运行时确定。
        // 此方式可突破 255 个成员的限制。
        // MO_MATH "Abs" {-100} CALL[3]         //=> 100
        // MO_MATH "Max" {-1} {99.0} CALL[4]    //=> 99.0

225-249 （未用）

250     MO_FMT(1){}     数据格式化（Go:fmt）
        // 汇聚基本的格式化方法。
        // 主要是对 go.fmt 标准库的局部成员封装。
        // 附参：方法名索引。
        // 实参：无。
        // 除了零值附参保留外，最多可支持255个方法名。
        // 成员：
        // - Sprint(a ...any) string
        // - Sprintf(format string, a ...any) string
        // - Sprintln(a ...any) string
        // 方法索引按上列顺序从 1 开始。
        // 私有域：整个模块仅供私有应用使用。
```
