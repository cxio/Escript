# 模块指令

模块用于引入分门别类的功能板块。

模块中定义的方法可以通过两种方式调用：*静态索引*；*动态方法名*。

除系统内置对象（`Time`, `RegExp`）外，其它模块的零值附参索引模块的构造方法，创建一个模块对象，用于通用的 `CALL` 调用其开放的方法。

> **约定：**
> 模块成员函数返回多个值时，会被封装为一个切片。无自动展开能力。


## 定义

指令码区间：`[221-250]`，30个。


### 标准模块

```go
码值    指令字          说明
-----------------------------------------------------------
221     MO_TIME(1){}    时间处理
        // 用于有关时间的更进一步处理。
        // 部分不确定性的方法只能由私有应用使用。
        // 附参：方法名索引。
        // 成员：
        // 所有方法的首个实参为一个 Time 对象。
        // ……待补充

222     MO_RE(1){}      正则表达式
        // 对正则表达式的完整方法集的定义和处理。
        // 静态的确定性方法便于公共域使用。
        // 附参：方法名索引。
        // 成员：
        // 所有方法的首个实参为一个 RegExp 对象。
        // ……待补充

223     MO_MATH(1){}    数学运算类
        // 汇聚专用于数学运算的高阶操作。
        // 附参：方法名索引。
        // 0: 系统保留，用于创建模块对象。可用 CALL 调用。
        // 1-255: 方法名索引。
        // 说明：
        // 除了零值附参保留外，最多可支持254个方法名。
        // 成员：
        // T: 支持 Int 和 Float，返回值类型即参数类型。
        // - Abs(x T) T
        // - Ceil(x T) T
        // - Floor(x T) T
        // - Pow(x, y T) T
        // - Max(x, y T) T
        // - Min(x, y T) T
        // - Mod(x, y T) T
        // - ……待补充
        // 例：
        // 静态引用方法索引，此处花括号内的名称为索引别名。
        // 静态引用对公共域更友好。
        // {-100} MO_MATH{Abs}      // => 100
        // {-100} MO_MATH[1]        // 同上，假设 Abs 索引为 1
        // {1} {99.0} MO_MATH{Max}  // => 99.0
        //
        // 例：
        // 也可以使用 CALL 调用，方法名为字符串，运行时确定。
        // 此方式可突破 254 个成员的限制。
        // MO_MATH "Abs" {-100} CALL[3]         //=> 100
        // MO_MATH "Max" {-1} {99.0} CALL[4]    //=> 99.0

224     MO_FMT(1){}     数据格式化（Go:fmt）
        // 汇聚基本的格式化方法。
        // 主要是对 go.fmt 标准库的局部成员封装。
        // 附参：方法名索引。
        // 实参：无。
        // 除了零值附参保留外，最多可支持254个方法名。
        // 成员：
        // - Sprint(a ...any) string
        // - Sprintf(format string, a ...any) string
        // - Sprintln(a ...any) string
        // ……待补充

225-250 （未用）
```
