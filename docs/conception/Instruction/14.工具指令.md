# 工具指令

包含一些基础并常用的功能性指令。另外还有一个保留区（量子安全）。


## 定义

指令码区间：`[138-163]`，26个。

```go
码值    指令字      说明
-----------------------------------------------------------
138     EVAL        执行脚本
        // 将实参视为脚本指令序列执行。
        // 拥有独立的「执行环境」，与外部隔离，
        // 但内部数据栈的遗留项会作为一个切片返回到调用层。
        // 实参：Script。
        // 返回值：一个切片。
        // 注意：
        // 实参是有类型的，仅能由 CODE、SCRIPT 创建。
        // 注记：
        // 暂无向这个独立环境传递初始栈条目的设计。
        // 因此 CODE/SCRIPT 的指令序列需要自我完整（无传参）。
        //
        // 设计：
        // 本指令相对封闭，拥有独立环境，与外部的关系为：
        // - 脚本内的通关状态（PASS/CHECK）与调用层无关，PASS(false) 不透传。
        //   即 PASS(false) 只是简单终止，退出到外部调用层继续。
        // - 脚本内的 END/INPUT 公共域终止逻辑与 PASS 类似，
        //   该封闭环境的公共域结束后，退出到外层继续，不影响外层公共域逻辑（同 EXIT）。
        // - 与正常的退出和公共域结束不同，EVAL 内部的错误会导致执行失败，
        //   错误/失败会向外传递，导致外层也失败并结束脚本（验证不通过）。
        // - EVAL 与外部调用者的交互通过内部的数据栈存留来实现。
        // 也即：
        // - 本指令主要用于运算拆解，而非通关检查拆解。
        //   因为通关检查拆解已经有 GOTO/EMBED 等指令承担。
        // - 因此 EVAL 的功能，有点类似于自定义函数：
        //   CODE/SCRIPT 定义，EVAL 执行。但错误会导致整体失败。
        //
        // 提示：
        // 没有办法传递出 EVAL 内的通关状态，但「是否通过」的逻辑可由栈数据存留间接表达。
        // 此时可不用 PASS/CHECK，而只是将必要的 false/true 写入栈即可。
        // 当然，也可以用 ENV{Passed} 提取状态，但注意 PASS(false) 会立即结束。
        //
        // 约束：EVAL 不可嵌套，其中不能再有 EVAL 指令。

139     COPY        复制（字典）
        // 创建一个新的字典对象，并复制其键/值。
        // 键对应的值本身是浅复制（一个新的引用）。
        // 实参：一个字典对象。
        // 返回值：原值和一个新对象。
        // 展开：两个返回值自动展开到目标区。
        //
        // 设计：
        // 因为字典对象是可变的，所以提供此复制功能。
        // 键对应的值本身不能被修改，所以浅复制没有问题。

140     KEYVAL(1)   键/值切取（字典）
        // 附参：切取类型。
        // - 0: 键和值。两个切片。
        // - 1: 仅键。一个切片。
        // - 2: 仅值。一个切片。
        // 实参：一个字典对象。
        // 返回值：1~2个切片。
        // 返回两个切片时，两者的成员会一一对应。
        // 两个结果会自动展开到目标域。
        // 例：
        // @KEYVAL  键值两个切片展开到实参区。此时实参区有两个切片

141     MATCH(1){}  正则匹配
        // 对字符串或字节序列进行正则匹配，取匹配值或子匹配的值。
        // 会根据目标值的类型（String|Bytes）自动选择合适的处理函数。
        // 附参：匹配方式（g|G|f|S|_）。
        // 实参1：目标字符串或字节序列。
        // 实参2：正则表达式（*RegExp）。
        // 返回值：布尔值|单值|切片。
        // 附参值：
        // [0]：零值，匹配测试（re.Match），返回Bool。
        // 'g'：查找所有，但仅限于完整匹配（re.FindAll|FindAllString）。
        // 'G'：查找所有，包括捕获组（re.FindAllSubmatch|FindAllStringSubmatch）。
        // 'f'：查找首个匹配（re.Find|FindString），返回单值
        // 'S'：查找首个匹配，包括捕获组（re.FindSubmatch|FindStringSubmatch）。
        // 注意：
        // 如果正则式不含子匹配式，想要获取全部匹配应当使用 g 标记，
        // 因为 G 标记确定会返回一个二维切片。
        // 例：
        // /(?i)[a-z]+/ MATCH{g}        获取全部完整匹配，结果是一个切片
        // /(?i)[a-z]+/ MATCH[103]      同上，用 g 的 ASCII 码值表示
        // /(?i)Ver-(\d+)/ MATCH{G}     获取全部匹配，包含子匹配，结果是一个二维切片
        // /(?i)Ver-(\d+)/ MATCH{S}     获取首个匹配。返回的切片包含了两个成员
        // /(?i)[a-z]+/ MATCH{f}        获取首个匹配。返回一个单值
        // /(?i)\b[0-9a-f]+\b/ MATCH    是否包含一个十六进制数，默认0值省略

142     SUBSTR(~)   字串截取
        // 附参：符文（Rune）数量。零值表示目标位置之后全部。
        // 实参1：一个字符串（UTF-8）。
        // 实参2：起始字符位置。按字符计数，从0开始。
        // 返回值：一个子字符串。
        // 注意：
        // 实参1通常为合法的UTF-8序列，遇到非法字节会被丢弃。
        // 因此这实际上可以作为一个正确 UTF-8 过滤器。
        // 如果截取的子字符串长度不足，返回已截取的部分。
        // 注意：
        // 如果想要截取通用的字节片段，应当使用 SLICE。
        //
        // 设计：
        // 作为栈脚本，使用静态的附参定义字符数量更安全。

143     REPLACE(1)  字串替换
        // 对目标字符串中匹配的部分进行替换。
        // 附参：替换次数，0值表示全部。
        // 实参1：目标字符串。
        // 实参2：替换匹配式（子串或正则表达式）。
        // 实参3：替换串，可包含特殊标识（当匹配式为正则表达式时）。
        // 返回值：一个新的字符串。

144     RANDOM      随机数生成（确定性）
        // 创建一个随机数，随机数种子由实参提供。
        // 实参1：随机数种子，32字节序列。
        // 实参2：上限边界（不含），支持 Int|Float 两种类型。
        // 返回值：一个小于实参的非负随机数，类型与实参2相同。
        // 设计：
        // 采用基于 BLAKE3 的 Keyed + XOF（可扩展输出）模式生成随机数。
        // 算法：
        // stream(seed, tag)
        //      key = seed
        //      tag = "Escript/RANDOM/v1"
        //
        // next64()
        //      从流中读取下 8 字节，按大端序解释为 uint64。
        //
        // uniform(n)，n ≥ 1
        //      r = (2^64 − n) mod n
        //      循环：x = next64()，直到 x ≥ r
        //      返回 x mod n
        //      （拒绝采样，没有取模偏差；期望读取次数小于 2）
        //
        // RANDOM(seed, bound Int)
        //      bound ≥ 1，否则失败；返回 uniform(bound)。
        //
        // RANDOM(seed, bound Float)
        //      x = next64() >> 11；返回 x / 2^53 × bound。

145     SLRAND      切片成员乱序（确定性）
        // 将切片成员随机重排。
        // 切片兼容字节序列（字节切片）类型。
        // 实参1：随机数种子，32字节序列。
        // 实参2：一个切片或一个字节序列（Bytes）。
        // 返回值：一个新切片或新的字节序列。
        // 算法：
        // 参见上面 RANDOM 的算法示意。
        //
        // tag = "Escript/SLRAND/v1"。
        // SLRAND(seed, s)      // s 为实参2
        //      t = s 的副本
        //      i 从 len(t) − 1 递减到 1：j = uniform(i + 1)；交换 t[i] 与 t[j]
        //      返回 t
        //      （Fisher–Yates 洗牌）
        //
        // 例：
        // DATA{<rand_seed>}    // 初始随机数种子（32 Byte）
        //
        // TOP                  // A.种子副本
        // {10} {2} RANGE[10]   // 生成一个连续偶数序列 {10, 12, 14, ...}
        // SLRAND               // 消费 A，随机偶数序列入栈
        //
        // PEEK[-2]             // B.种子副本
        // DATA[10]{...}        // 10字节目标数据（字节序列）
        // SLRAND               // 消费 B，随机字节序列入栈
        //
        // @POPS[2]             // 提取两个随机序列放入实参区
        // OUTPUT               // 导出两个随机序列
        //
        // _POP                 // 移除原初始随机数种子（栈顶剩余）

146     CMPFLO(1)   浮点数比较
        // 附参：比较类型标识。
        // > 0  相等比较（==）
        // > -1 小于等于（<=）
        // > 1  大于等于（>=）
        // 实参1：待比较值。
        // 实参2：待比较值。
        // 实参3：误差值，实参1-2间的差值不超过该值时即视为相等。
        // 返回值：一个布尔值。
        //
        // 设计：
        // 主要用于弥补比较指令中对浮点数相等测试的不足。
        // 如果不涉及相等的大于或小于对比，使用比较指令更便捷。

147     CALL(1)     调用（对象|模块）
        // 对目标集合中的方法执行调用。
        // 附参：实参数量（含实参1/2），零值表示取实参区全部。
        // 零值时实参区必须有值（至少1项），无方法名时什么都不做，但消费实参。
        // 实参1：目标集合，必需
        // 实参2：方法名（大小写敏感），可选。空时无行为。
        // 实参...：方法需要的实参序列。
        // 返回值：目标方法调用的结果。
        // 如果方法返回多个值，会被封装为一个切片（单值）。
        // 例：
        // DATE{2026-03-21T19:08:50Z}
        // TOP "Day"            // TOP 引用栈顶，不弹出维持后用
        // &CALL[2]             //=> 21 暂存
        // TOP "Clock"          // TOP 引用不弹出
        // &CALL[2]             //=> [19, 8, 50] 暂存
        // "Format" "15_04_05"  // 不再引用 DATE，会弹出作为首个实参
        // &CALL[3]             //=> "19_08_50" 暂存
        // &[-3] &[-2] &[-1]    // 提取局部域暂存值
        // PUSH                 // 21, [19, 8, 50], "19_08_50" 入栈
        // SHIFT[3]             // [21, [19, 8, 50], "19_08_50"] 入栈
        //
        // 例：
        // BLOCK{               // 创建一个局域便于存值
        //     MO_MATH
        //     TOP "Abs" {-10}  // TOP 仅引用 MO_MATH
        //     &CALL[3]         //=> 10  暂存
        //     "Pow" {2} {8}    // 栈顶依然为 MO_MATH，将被取出
        //     &CALL[4]         //=> 256  暂存
        //     &[0] &[1]        // 提取两个暂存值到实参区
        //     PUSH             // 10, 256 两项入栈
        // }
        // SHIFT[2]             // 栈顶2项打包为切片
        // ANYS{Float}          //=> [10.0, 256.0]  转换为浮点数序列
        //
        // 例：
        // MO_FMT               // fmt 模块
        // "Sprint"             // fmt.Sprint(a ...any) 不定参数
        // DATE{1606227845000}  // 一个Time
        // CALL[3]              // 实际向 Sprint 传递一个实参
        //
        // 例：
        // DATE{2026-03-21T19:08:50Z}
        // CALL[1]              // 无方法，无结果。消费栈顶项，同移除该条目。
        //
        // 设计：
        // 本指令是通用的，可以解耦模块中方法的固定配置。
        // 同时它也适用于对象，如内置的正则表达式、字典和时间对象等。
        //
        // 模块和对象中哪些方法可用，有脚本系统的版本约束。

148-151 （未用）

152     RANGE(1)    创建数值序列
        // 附参：序列长度（成员数量）。
        // 实参1：起始值，Int|Float。
        // 实参2：步进值，Int|Float。
        // 整数（公域）使用逐次累加（val += step）。
        // 浮点数（私域）使用乘法计算（start + i×step）。
        // 返回值：一个数值切片。
        // 说明：
        // 返回类型由实参表达：全部整数时为整数，有任意浮点数时自动提升。
        // 附参0值会创建一个空切片，此时的任意实参仅表达类型。
        // 例：
        // {10} {1} RANGE[5]    // [10, 11, 12, 13, 14]
        // {1} {1.1} RANGE[5]   // [1.0, 2.1, 3.2, 4.3, 5.4]
        //
        // 设计：
        // 附参仅由1字节表达，因此仅用于创建小数值序列。
        // 这是基于性能和安全性的考虑。
        // 如果需要较大的集合，可以考虑合并多个结果（MERGE）。
        // 例：
        // {0, 250, 500, 750}
        // EACH{
        //      $Value {1} RANGE[250]
        // }
        // @POPS[4] MERGE   // [0, 1, 2, ...999]

153     MAP{}(~)    映射迭代
        // 针对目标集，迭代每一个成员执行子语句块，
        // 返回值构造为一个最终切片。
        // 附参：子语句块长度。
        // 实参：不定数量。
        // 首个成员为目标集，后续作为私有域数据栈初始成员。
        // 返回值：一个切片。
        // 语法：
        // 内部语句块视为一个私有的块域：
        // - 拥有自己的独立数据栈和实参区，与上层调用者无关。
        // - 各个迭代之间共享数据栈和实参区（注意@实参可延续到下一迭代）。
        // - 全局变量空间并不私有，和外部调用层共享。
        // 提示：
        // 私有块域并不隔离 PASS/CHECK，通关状态属于上层脚本域。
        // 也即私有域内的 PASS(false) 会结束上层脚本，并透传到最终验证。
        // 局部变量：
        // - $Value     // 当前条目数据
        // - $Key       // 当前循环键（整数下标或字符串）
        // - $Object    // 迭代集本身
        // - $Size      // 集合大小（迭代次数）
        // 注意：
        // 返回的 nil 值会被忽略，这让指令也有了筛选的能力。
        // 目标集可以是切片或字典，如果是后者，迭代的顺序为插入时的顺序。
        // 例：
        // @{1, 2, 3, 4}    // 目标集
        // @{20}            // 私有数据栈初始成员
        // MAP{
        //      @( $Value * TOP ) RETURN
        //      // TOP无前置@，这是表达式内的规则
        // }
        // 返回集：[20, 40, 60, 80]
        //
        // 设计：
        // 可以通过 RETURN 退出当前迭代，进入下一次迭代。
        // 但没有中途退出 MAP/FILTER 私域块的语法，目标集成员始终会被遍历。

154     FILTER{}(~)     成员过滤
        // 针对目标集，迭代每一个成员执行子语句块
        // 返回真时该成员被选取（不影响原集合）。
        // 附参：子语句块长度。
        // 实参：不定数量。
        // 首个成员为目标集，后续作为私有域数据栈初始成员。
        // 返回值：一个切片或字典。
        // 语法：同上 MAP 指令。
        // 说明：
        // 支持字典的过滤，返回真的条目构建为一个新的字典。
        // 返回值类型同目标集，切片=>切片，字典=>字典。
        // 例：
        // @{1, 2, 3, 4, 7}     // 目标集
        // @FILTER{
        //      ( $Value % 2 )  // 奇数值为1
        //      @BOOL RETURN    // 转为布尔值返回
        // }
        // PRINT    // 打印 [1, 3, 7]

155     SHELL{}(~)      Shell 命令执行
        // 在一个独立的环境中执行 Shell 命令。
        // 不限定语言，首行标记解释器（Shebang）即可。
        // 附参：内容长度。
        // 数据：实际的脚本代码内容。
        // 返回值：脚本的返回值（单个）。
        // 说明：
        // 始终返回一个值，若脚本无值返回，则返回一个 nil。
        // 私有域，仅由有需要的私有节点使用。
        // 与浮点值指令和 SYS_TIME 等类似，公共验证遇到即为失败。
        //
        // 设计：
        // 通过公共链发布某种本地需求，可能是一个必要的功能。
        // 公共域非法，是因为它不应当影响公共验证的基础性支撑。
        //
        // 它私有通用，但默认关闭，具体应用应当设计自己的白名单机制。
        // SHELL 作为基础指令存在，是为了一致性命名。
```


## 保留区

主要用于未来可能需要的基础性安全支持，比如抗量子能力。共计 8 个，范围：`156-163`。
